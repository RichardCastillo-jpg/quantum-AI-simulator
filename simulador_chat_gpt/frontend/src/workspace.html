Convenciones del circuito

Lee los pasos de izquierda a derecha. La cadena inicial y los resultados siguen el orden qₙ₋₁ … q₀. El cable superior es q₀. Todos los ángulos se expresan en radianes.

Modos de ejecución

Statevector presenta las probabilidades exactas. Shot añade frecuencias de mediciones finales y el contenido de la memoria clásica. Una medición intermedia o el ruido pueden producir un estado mixto. En ese caso la esfera representa el vector reducido y la tabla muestra poblaciones.

API REST

POST /simulate valida y ejecuta un circuito. GET y POST /subcircuits consultan y crean bloques. PUT y DELETE /subcircuits/{id} actualizan y eliminan definiciones.

Ruido

Después de cada compuerta unitaria, cada cúbit implicado recibe un canal independiente. El canal despolarizante usa λ = 0,01. La relajación térmica usa T₁ = 50 µs, T₂ = 70 µs y duración de 200 ns.
